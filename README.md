# 识矿 2.5 预览版

以手机上的矿物标本识别为核心。网页版与 Android 使用相同的识别逻辑、知识库和界面。

面向实验室同事的不同手机和电脑。Android 安装版要求 Android 7.0（API 24）及以上和可用的系统 WebView，具体设备的相机、内存和识别效果仍需实测。照片文件支持 JPEG、PNG、WebP，限 20 MB、4000 万像素，先读取压缩头检查尺寸再解码；HEIC、AVIF 或无法读取尺寸的文件请先转换。相机与视频直接缩小画布，分析图最长边 1536 像素。读取可取消，离开识别页或开始新标本会拒绝旧任务的迟到结果；已提交照片与保存记录分别保留。合法高像素照片仍可能超出低内存设备的能力。

## 本次升级

- 拍照、视频、照片文件独立入口，视频在本机取帧；启动封面可跳过并限时结束。
- 工作线程运行推理、模型 SHA-256 校验、读取进度、停止分析与 120 秒上限。
- 原生拍照与相册导入，同一标本最多 3 个不同角度；预览框与实际中心裁剪区域一致。
- 按校验后的模型清单确定快速或多模型模式；稳定 softmax 后按模型和照片等权汇总，拒绝缺失模型或迟到的旧任务结果。
- 低质量照片引导重拍；等待非标本筛查完成；移除容易误拒红褐色矿物的肤色规则。
- 展示候选、模型一致度与不确定原因。输入硬度、光泽只与有原始来源且已经核验的物性比较；待复核资料不参与冲突结论，不提高图像分数。
- 原有 105 条知识资料与 6,239 个 IMA 官方目录条目合并检索，同种矿物的明确别名合并成一张卡；8/9/10 类筛选不会把未收录分类自动补成已知分类。图像模型仍为原有 98 个标签，包含矿物、变种、集合体和部分岩石。
- 图鉴按需加载并校验资料文件；大目录、晶胞与图库 JSON 仅在首次进入图鉴或手动准备离线资源时下载，启动和 Service Worker 初次安装不隐式下载大库，识别首屏不等待完整目录；每次显示 80 项，可按扩展资料、模型范围、晶胞记录筛选，支持英文名称和化学式离线搜索。
- 5,366 个精确匹配的官方 Handbook PDF 链接；9,895 条文献晶胞记录关联 3,430 个官方矿物名称，保留样品条件、单位、空间群与原文出处。
- 对 89 个原知识条目标签，从 88 个不同 Handbook PDF 提取并核验 477 个物性字段。逐字段保留原文、单位、页码及核验状态；缺失、`n.d.` 和来源推测不会冒充实测物性。
- 871 条图片出处，涉及 131 个来源名称。117 张内置真实矿物照片覆盖 53 个原标签，其中 52 个精确 IMA 物种与 Tetrahedrite 群；逐图保留作者、许可、源图与导图哈希、实际裁剪修改和审核证据。展开图库后才读取并核验照片，断网可对照；754 条其余出处仍未通过照片训练准入。来源标签研究准入不等于独立实验室鉴定，也不代表随包权重已训练这些照片。
- IndexedDB 标本记录、缩略图、编号、备注、人工确认方法、JSON 导入导出；同一网页源中的旧历史可迁移，Android 跨包数据需人工备份，不能自动迁移。
- 常见物性使用中文显示，原始术语与逐字段出处可查；化学式使用可复制的上下标。晶族、七晶系及多型条件分别说明，不将 Handbook 的 Hexagonal 一律显示成六方晶系。
- 晶体图标、手机底部导航、响应式布局、识别扫描动效和页面过渡；遵循减少动画偏好。
- 修复离线缓存与 GitHub Pages 子目录回退。发布文件不再包含共享 API 密钥。
- DeepSeek V4.1 Flash 用于可选的资料辅助，用户自行提供本次会话密钥，默认不上传照片；明确勾选后可附加照片，不修改本机候选分数。

## 准确率验证

本轮完成两次真实照片重训：预先选定八类、168 张审核通过照片、158 个保守来源/重复组，以逐类按组约 80/10/10 划分，使用可核验的官方 ImageNet 初始权重重新初始化矿物分类头。第一轮出现明显过拟合；第二轮固定骨干和 BatchNorm，仅训练新分类头。验证集温度校准后的多模型 Kappa 为 0.7410；锁定的 14 组来源照片盲测 Kappa 为 0.6564，组重采样 95% 区间约为 [0.3671, 0.9054]，未达 0.95。转向压力测试亦暴露泛化不足，候选在读取测试结果前就已决定不进入正式包。具体权重/分区哈希、两轮训练历史、逐图来源和许可、单模型及多模型结果见 [重训报告](docs/model-validation/retraining-pilot8-20261011.json)。此小样本来源照片试验不能代表所有矿物、复杂实验室标本、未知拒判或手机链路准确率；不得重测已公开测试集后称为新的盲测。

随包保留 1.0 的权重与 98 个标签顺序，通过 SHA-256 防止文件或标签表意外变化。[旧数据审计](docs/model-validation/legacy-data-audit.json)发现旧验证与测试照片大量重复于训练集，旧 Kappa 不能作为独立验收依据。IMA 化学式与已核验的 Handbook 物性有逐项出处；原项目形成、产地、用途及未标官方出处的旧属性仍待复核，缺失物性不用于复核。

阈值目前为模型分数 0.65、首选与次选差距 0.20、模型一致度 2/3、各角度首选一致。这些是预览版的拒判规则，尚未通过现场样本校准。“线索较一致”仍是待复核候选，不能证明样本属于已覆盖类别。图像质量与 ImageNet 筛查也只是启发式规则，不能可靠拒绝所有未覆盖矿物、岩石或非矿物。

将 `tools/samples-template.csv` 复制到数据集目录，填写真实标本：

- `split` 为 `calibration` 或 `test`，同一实物标本只能属于一个分区。
- `specimen_namespace` 是实验室或收藏机构命名空间，`specimen_id` 是该机构的实物编号；每个标本 1–3 张照片，禁止重复图片。已知近重复、不同角度或裁剪的同一实物应合组，程序的 SHA 检查不能代替这一审核。
- `scene` 为 `lab` 或 `daily`；`label` 使用 `model-manifest.json` 中的模型键，未覆盖矿物、岩石、动物、日用品使用 `unknown`。
- `image` 相对 CSV 路径；`crop` 为中心裁剪比例 0.5–1，默认 1；实测 `hardness` 和 `luster` 可留空，光泽选 `metal` 或 `nonmetal`。
- `label_basis` 记录真值依据及报告编号或来源，例如 XRD 检测、核验过的馆藏记录，非矿物也记录观察依据。不能把 App 自己的候选当成真值；填入文字本身不构成独立鉴定证明。

```sh
python3 -m pip install -r tools/requirements.txt
python3 tools/predict_samples.py /path/to/samples.csv --out /path/to/raw.json
node tools/evaluate.cjs /path/to/raw.json > /path/to/report.json
node tools/evaluate.cjs /path/to/raw.json fast > /path/to/fast-report.json
```

报告按分区和场景分别给出 Top-1、Top-5、宏平均 F1、Cohen Kappa、强线索覆盖率、强线索子集正确率、未知类误报率与拒判率。V3 原始输出绑定清单 SHA、各模型 SHA、当前温度及照片 SHA，拒绝旧版无身份结果或不完整模型输出；快速与多模型分别计算。质量与拒判规则调用共享 JavaScript 逻辑。Python 与 Canvas 重采样的真实照片差异已观察到，几何一致不等于分数一致；最终应在不同性能与 Android/WebView 版本的手机验证。没有真实数据时工具明确失败，不生成空准确率。

正式验收应包括实验室干净背景、生活复杂背景、光照与反光变化、模糊、共生/多矿物、相似矿物、未覆盖类别，并按不同实物、设备划分校准与盲测集。预览包通过构建与逻辑测试不等于通过准确率验收。

## 资料与 API

原知识库及模型来自所提供项目。手机拍照使用 [Capacitor 6 Camera](https://capacitorjs.com/docs/v6/apis/camera)，文字补充使用 [DeepSeek 官方 Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。版本与模型文件信息见 `model-manifest.json`。

6,239 项采用 [IMA-CNMNC 2026 年 9 月清单](https://cnmnc.units.it/files/editor/IMA_Master_List_(2026-09).pdf)。它是该版有效矿物目录，状态含 A、G、Rn、Rd、Q 与 A ?，不等于所有条目都是新矿物批准状态 A，也不等于本 App 可以识别全部 6,239 种。首次发现国家不是当前标本产地；文献中的晶胞只描述对应样品。

官方清单按 CC BY-SA 3.0 保留归属、改动说明及许可，完整署名随包位于 `data/licenses/ima-cnmnc-2026-09.txt`。Handbook 仅收录书目/链接索引与选定科学事实，未打包 PDF 全文。图片许可与标签质量分别审核，公开许可不证明标签正确。其他指定网站及 Z-Library 书目线索继续显示真实采集状态，未采集站点不会标为已训练。完整说明见 [DATA-SOURCES.md](DATA-SOURCES.md)。

### 离线使用与安装升级

Android 包内置模型、运行时、目录与文献元数据，开发者电脑关机不影响本机识别。网页版须先在设置中完成“准备离线资源”；浏览器可回收缓存，现场使用以安装包更稳妥。官网清单、Handbook PDF 全文、图库原页以及 DeepSeek 辅助均需联网。

2.0.2 首次公开交付采用持续签名的预览包，旧 2.0.0-preview 的临时 debug 私钥未恢复，不能保证覆盖安装。先从旧 2.0 预览版导出 JSON 标本备份并保存到设备，再卸载旧预览版、安装新版、导入备份。卸载前未导出的记录无法靠跨包迁移恢复。原 1.0 App 可保留，其原生数据不会自动进入 2.0。已使用当前持续签名的预览版可按相同包名与签名更新，升级前仍建议导出备份。

### 新用户使用指南

首页的“快速上手”及设置中的“打开使用指南”提供六步引导：了解识别/图鉴/标本/设置 → 提交标本 → 补充观察 → 阅读和复核候选 → 准备离线或联网辅助 → 保存与备份。

同一标本重试、换精度或修改裁剪后再次保存会更新原记录；“开始新标本”只清空当前草稿，未保存输入会先确认，不删除已有标本。图鉴说明目录范围、来源与晶胞/图库的使用边界。

## Android 构建与第二轮平台验收

Android 预览版 2.5.0-preview.1，versionCode 25001，包名仍为 com.shikuang.app.preview；使用同一持续预览签名覆盖更新，升级前建议导出标本备份。当前本地同步内置 158 个应用资源，包括 117 张经来源与许可审核的真实矿物对照照片；该同步尚未构建新版 APK 或完成真机验收，此图库不代表随包模型已训练这些照片或独立实验室确认。原 98 标签权重保留，manifest 为 inherited-2.0-audited；新增八类盲测 Kappa 未达到目标，不替换当前模型。

最低 Android 7.0/API24，系统 WebView 需具备 Chrome83及以上的现代语法、Promise、URL、AbortController、crypto.subtle 与图片解码能力。旧组件显示可见更新指引并保留历史；首次更新组件需联网。使用 Node20+、JDK17、AndroidSDK：npm run sync 逐字节核对资源，然后 android/ 中运行 ./gradlew assembleDebug lintDebug。固定 ORT1.24.3、四 ABI 与压缩原生库；官方 SDK35 ZIP/ELF16KB 门与真实 16KB 模拟器分别验证。

第二轮包含 API24 原厂 WebView 恢复页、API30/35 与 API35 真正16KB断网识别流程，全部117张JPEG的真实Android解码与SHA核对，以及WebView实际图库照片Blob核验、关闭释放、重新打开。测试结果按 head/run 记录；模拟器通过不等于实体ARM64、所有品牌、相机权限或低内存机型已经实测。源码同步身份见 docs/ANDROID_SOURCE_SYNC.json。
