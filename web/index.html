怎样得到更可靠的线索

  1. 单独拍摄目标标本，使用均匀光线和简单背景。
  2. 拍摄不同角度与晶体细节，避免放入其他标本。
  3. 比较候选的硬度、光泽、条痕、晶形等信息。
  4. 实验室记录可补充已确认名称与确认方法。

随包识别仍使用原有 98 个图像标签。新模型仍在开发验证中，尚未完成独立测试 Kappa 约 0.80 的本次验收目标；开发试验权重未替换随包模型。模型分数不是现场准确率；相似矿物请结合物性和实验室检测复核。

新用户使用指南

认识你的矿物工作台

第 1 / 6 步

识矿帮助你从标本外观获得矿物候选，再对照物性和资料，保存可追溯的观察记录。适用于日常观察与实验室初步筛查。

识别
拍照、视频取帧或导入照片，分析候选名称，比较不同角度与模型的判断。
图鉴
搜索名称、英文名或化学式；按 8 / 9 / 10 类体系浏览物性、形成环境、典型产地与用途。
标本
保存照片、候选、备注与编号，补充已确认名称和确认方法，导出备份。
设置
准备离线资源、查看资料来源，或在联网时获取 DeepSeek 辅助说明。

使用顺序：提交标本 → 补充观察 → 分析候选 → 对照复核 → 保存记录。

每次只分析同一标本。使用均匀光线与简单背景，让目标居中、对焦清晰，尽量补充 2–3 个不同角度。

拍摄标本
打开相机拍摄一张照片；允许相机权限后再拍摄。
视频
选择录制或导入视频，缓慢展示同一标本。本机抽取画面供分析；最多保留 3 张图像。录制限 20 秒，导入限 90 秒、100 MB。
照片文件
选择 JPEG、PNG 或 WebP 照片，每张不超过 20 MB、4000 万像素；同一标本最多 3 张。HEIC、AVIF 或无法读取尺寸的文件请先转换格式。尺寸通过检查后才解码，保存的分析图最长边为 1536 像素。

提交成功后会显示照片预览和“已提交”提示。拖动“中心分析区域”减少背景干扰；可移除照片并重新添加。更换实物前点击“开始新标本”；未保存的当前输入会先询问，已保存记录保留。视频帧可能相似，不等于独立拍摄角度。

在“补充观察”填写颜色、晶形、条痕、磁性、采集信息等。照片是图像分析的输入；文字用于记录与联网辅助说明。

  1. 日常观察可直接使用默认场景；实验室场景会展开物性复核和标本编号。
  2. 已测量的摩氏硬度与观察到的光泽，用于提示候选是否符合或冲突。未测量的项目留空。
  3. 点击“分析矿物候选”。多模型与快速模式按当前模型清单运行，实际参与数量在结果中显示。
  4. 查看资源加载和分析进度。需要时点击“停止分析”；视频取帧也可停止。失败后照片会保留，可点击“重试分析”或“检查识别设置”。

修改照片或物性后应重新分析。填写描述不会提高图像模型分数；不规则、混合或细小标本可增加背景干扰，建议补拍整体和局部细节。

结果会展示首选与其他候选、图像模型分数、多角度及模型一致性，并提示实测物性的符合或冲突。

  1. 先看判断状态和候选差异，再打开“查看资料”核对硬度、光泽、晶形等依据。物性默认中文展示，可展开查看来源原文与页码；“原文待翻译”表示尚未完成中文翻译。化学式可复制，上下标按原式保留。
  2. 分数代表模型对当前照片的偏好，不等于准确率；分数较高仍可能识别错误。
  3. 分数低、判断不一致或物性冲突时，补拍细节、调整分析区域，必要时用实验室检测确认。
  4. 检测到非矿物时会提示：“这不是矿物，请您放入清晰的矿物照片。” 未覆盖对象仍可能误判，应结合实物复核。

目前沿用 98 个图像标签，资料库范围更广；分类目录不代表所有天然矿物都可识别。资料中的产地为典型产地，不能确定这块标本的真实采集地点。

鉴定方法依据
  • 物性与成分、结构有关，同种矿物也可能有差异；肉眼鉴定需结合形态、物性与成因产状。
  • 不能唯一定名时，先保留少数候选。鉴定通常先做肉眼观察，再结合薄片显微观察，并按问题与精度要求选择进一步测试。
  • 采样应兼顾目的性、典型性、代表性与系统性；珍贵或完整晶形标本应小心采集、妥善保存。
  • 现代矿物测试涉及微形态、成分与同位素、结构，部分技术兼具多种分析功能。App 的照片候选不能替代实验室测试。

依据：赵珊茸主编《结晶学及矿物学（第三版）》第14章、第16章（含第241页）。

离线模式
图像分析在本机进行。Android 安装包内置模型；网页版先在有网时进入“设置 → 准备离线资源”，等待完成，并保留浏览器缓存。之后可在同一浏览器中离线使用。
联网模式
在设置中填写自己的 API 密钥，点击“比较图像与候选证据”，调用 DeepSeek V4.1 Flash 比较候选与观察。尚未取得本机候选时，可主动勾选图像辅助。密钥只在本次打开期间使用。
照片与联网辅助
本机识别不会上传照片。联网辅助默认只发送候选与文字观察；只有明确勾选才会发送各角度选定的中心区域。图像参考和纯文字比较分别标明，均不更改本机分数或人工确认。

Android 安装版要求 Android 7.0（API 24）及以上，并需要可用的系统 WebView；具体设备性能仍需实测。开发电脑关机不影响本机识别；联网辅助需要手机网络及可用的 API 服务。网页版首次准备资源需要网络，清除浏览器数据后需重新准备。首次加载失败可在设置中重新准备资源；可随时停止准备，已完成资源保留。再次准备会校验模型并修复损坏的缓存。

  1. 分析完成后点击“保存标本”，再从底部“标本”查看照片、时间、候选、编号与备注。
  2. 得到可靠鉴定后，在记录中补充已确认名称及确认方法，保留原始候选供追溯。
  3. 图鉴与标本支持搜索。在搜索框按回车或离开输入框后会保存搜索词；图鉴与标本分别显示各自的历史搜索，可再次点击使用。
  4. 标本页右上方可导出全部记录为 JSON 文件；在另一设备导入该文件即可迁移。导入与导出的文件上限均为 100 MB。重复导入不会覆盖已复核记录。

记录最多保存 100 条，搜索历史最多 20 条，均保存在当前设备。卸载或清除应用/浏览器数据可能丢失记录，请定期导出备份。指南完成后，仍可在“设置”中重新打开。
